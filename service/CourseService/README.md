# CourseService Module

This folder contains the CourseService module for all course-related API calls.

## Structure
- `index.ts`: Main service class for course APIs (initialize, get-active, check-and-create-next-batch)
- Add any helpers, utils, or types for course features in this folder.

## Usage
Import from:
```ts
import { courseService } from "@/service/CourseService";
```
